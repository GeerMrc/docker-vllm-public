*可用上下文 = max_model_len - 8K (估算 sys prompt + 工具定义占用)

决策规则

  1. 优先 140K — decode 37.6 tok/s, c=4 >200 tok/s, 可用上下文 ~132K，覆盖绝大多数 Agent 场景
  2. 避免 152K 除非必要 — decode 从 36 降至 24 tok/s (-33%)，仅当输入确实 >145K 时值得
  3. n=2 仅用于 c=2–3 — n=2 c=4 一致性退化至 ~80 tok/s，严禁 n=2 + c=4 组合
  4. gpu_util=0.96 保留 n=2 切换余量 — 140K + gpu=0.96 下 n=2 仍可正常工作 (prefill 上限 142,874 tok)
